# Learning Management System

A web-based Learning Management System developed as a team project using React, Node.js, Express.js, and MongoDB.

## My Contribution

I developed the Certification Management Module, including:

- Certificate generation and management
- Certificate viewing and verification
- Frontend certificate interfaces
- Backend APIs and database integration
- Testing and debugging

## Technologies Used

- React.js
- Node.js
- Express.js
- MongoDB
- JavaScript
